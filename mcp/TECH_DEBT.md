- [x] ~~**`mcp/` directory shadowed the `mcp` pip package.**~~ Fixed 2026-08-03 by deleting `mcp/__init__.py` (17 bytes, `# package marker`). Without the marker, `mcp/` is a namespace portion and a real package in site-packages wins from any position. The shims in `server.py:9-12`, `visualization_tool.py:6-9`, `data/alphavantage_tool.py:5-8` and `tests/conftest.py:20-21` stay — they serve sibling imports, not collision avoidance.
